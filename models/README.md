# 3D Model(s)

This is the housing for the gauge components, making an open-backed gauge shell for prototyping.

Gauge body is friction fit for **52mm** diameter pod housing
Utilizes the screws on the waveshare 1.85" LCD which are a M2.00 screw size.

Modeled / Written in [openscad](https://openscad.org/)

Initial model from https://github.com/gruntygap/cheapo-gauge
